# task_1 수행계획서: 카테고리 아이콘 공개 URL E2E 시드 보정

## 목표

프론트 E2E 시드가 Drive 공개 URL 형식을 사용하도록 수정한다.

## 현재 현상 또는 요구사항

- E2E가 삽입하는 카테고리 아이콘 URL에 `/public`이 없다.
- 실제 화면은 API 응답의 URL을 이미지로 렌더링한다.

## 확인 방법

- E2E 시드 URL 검색
- 린트 및 Vite 빌드

## 영향 범위

- 로컬 E2E 테스트 데이터

## 단계별 작업 개요

1. E2E 시드 URL을 보정한다.
2. 린트·빌드를 실행하고 `main`에 푸시한다.

## 승인

작업지시자의 추가 작업 지시로 승인되었다.
